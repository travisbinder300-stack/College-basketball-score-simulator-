# Basketball Score Simulator

This repository contains advanced basketball game simulators:

## NBA 10,000 Game Simulator

An advanced NBA game simulator using **Haralabos Voulgaris-style analytics** with **Kelly Criterion betting strategy**.

### Features

- **10,000 game simulations** for statistical accuracy
- **Haralabos Voulgaris-style analytics**: Four Factors, pace-adjusted efficiency, advanced metrics
- **Kelly Criterion betting strategy**: Optimal bet sizing and edge detection
- **Python-based**: No external dependencies required (Python 3.7+)

### Quick Start

```bash
# Run the main simulator
python3 nba_simulator.py

# Run betting analysis examples
python3 betting_examples.py
```
