# College Sports Score Simulator

This repository contains sports prediction systems for college athletics.

## College Football Score Prediction System

A Python-based prediction system that uses **FEI (Fremeau Efficiency Index)** methodology to predict college football game outcomes, including:
- Game winner and margin of victory
- Point spread for betting analysis
- Total points (over/under) for betting analysis
- Confidence ratings

### Quick Start

```bash
python3 football_predictor.py
```

For detailed documentation, see [FOOTBALL_PREDICTOR.md](FOOTBALL_PREDICTOR.md)

### Features
- ✅ Real FEI-based efficiency metrics
- ✅ Predicts spread and total for betting analysis
- ✅ Home field advantage calculations
- ✅ Interactive CLI for custom matchups
- ✅ 2022 season data for top teams
