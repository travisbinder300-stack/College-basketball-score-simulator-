# Data Templates - Fill With Your Own Data

## Overview

These are TEMPLATE files. Copy them to the `user_data/` directory and fill in with your actual 2025-26 NBA data.

## How to Use

1. Copy all `.json` files from this directory to `../user_data/`
2. Open each file and replace the template data with your real data
3. Run validation: `python validate_data.py`
4. Use your data in the analysis tools

## Template Files

- `players_template.json` - Player roster data
- `props_template.json` - Prop betting lines and statistics
- `lineups_template.json` - Lineup impact data
- `shot_charts_template.json` - Shot charts and defensive data

## Important

⚠️ **DO NOT use the example data provided** - it's for format reference only.
✅ **ALWAYS verify** player-team associations are current for 2025-26 season.
✅ **VALIDATE** your data before using it in analysis.
